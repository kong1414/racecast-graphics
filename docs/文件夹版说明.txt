APEX 赛车字幕 · Windows 文件夹便携版

一、运行
打开本文件夹，双击 APEX赛车字幕.exe。
无需安装 Node.js、npm 或其他开发工具。适用于 Windows 10/11 64 位电脑。

二、如何拷贝走
1. 退出软件，包括独立的 H5 输出窗口，等退出保存完成。
2. 将整个“APEX赛车字幕_拷贝此文件夹”文件夹复制到 U 盘、移动硬盘或另一台电脑。
3. 在新电脑上打开该文件夹，双击 APEX赛车字幕.exe。
不要只复制这个 EXE，也不要删掉 DLL、resources、locales 等运行文件。
不需要复制项目源码、node_modules、release 或原来的整个开发目录。

三、赛事数据也在文件夹里
“用户数据\projects\autosave.json”是当前工程自动保存，.bak 是上一个保存版本。
本包首次提供的是内置虚构演示工程，不会读取或复制本机其他位置的赛事数据。
以后请使用这个文件夹中的 EXE。通过这个版本编辑的赛事、名单、图片、图层与预设会保存到本文件夹。
整体复制文件夹即可一起带走。“工程备份”中的演示工程可通过“打开工程”导入。
此版本只在软件目录存在 portable-mode.json 时启用文件夹数据模式，请保留该文件。
请在可写目录运行，例如桌面、D 盘或 U 盘；不要放在只读目录或压缩包内部运行。

四、原来那个程序里又做了修改怎么办
如果你之后仍然使用旧路径的程序，那里的新修改不会自动同步到这个交付文件夹。
请在旧程序中点击“导出工程”，再到本文件夹版本中点击“打开工程”导入。
也可以把导出的 .apex.json 放到“工程备份”内一起拷走。

五、接入 OBS / vMix
保持软件运行，在“输出与设置”复制 H5 输出地址。
一般为 http://127.0.0.1:9860/output；端口占用时会自动改变，以软件显示为准。
OBS 添加浏览器源，设置 1920×1080；vMix 添加 Web Browser 输入。
该地址供运行软件的同一台电脑使用。

六、其他内容
“示例与模板”：空白赛事、演示赛事、车手与计时 CSV 模板。
“使用文档”：用户手册、功能说明、接口说明。
“工程备份”保存的是内置虚构演示工程，不会带入本机已有赛事数据。之后在这个文件夹中完成的修改，请在整体复制前正常退出软件，以带走最新保存。

# APEX 赛车字幕用户手册

本手册面向赛事字幕操作员，说明如何启动程序、建立赛事、维护车手与计时、切出字幕，并将透明画面接入 OBS Studio 或 vMix。

## 1. 开始之前

### 1.1 运行环境

- Windows 10/11 64 位。
- 便携版无需安装 Node.js。
- 源码版使用 Node.js 24 和 npm。
- OBS 或 vMix 与 APEX 运行在同一台电脑。
- 输出按 1920 × 1080 设计，可随浏览器源等比缩放。

### 1.2 启动便携版

1. 双击 `APEX-Race-Graphics-1.0.0-portable.exe`。
2. 首次启动需要解压组件，请稍等。
3. 控制台顶部显示「本地服务已连接」后即可操作。
4. 播出期间不要关闭 APEX；关闭程序后，OBS / vMix 将无法继续读取字幕页面。

如果使用完整文件夹版，必须保留 EXE 同目录下的 `resources`、`locales`、DLL 和其他运行文件，不能只复制 EXE。

### 1.3 从源码启动

在项目目录打开 PowerShell：

```powershell
npm ci
npm start
```

只需要浏览器控制台时，可改为：

```powershell
npm run server
```

然后访问 `http://127.0.0.1:9860`。

### 1.4 认识控制台

顶部有五个页面：

| 页面 | 用途 |
| --- | --- |
| 播出控制 | 编辑图层、检查预览、切出播出、清屏与场景预设 |
| 实时计时 | 排名、圈速、差距、状态、轮胎、分段与进出站 |
| 车手与车队 | 车手资料、车队、形象照和名单 CSV |
| 赛事管理 | 赛事资料、场次、旗号、时钟和成绩确认 |
| 输出与设置 | 输出地址、主题、数据接口、保存位置和操作记录 |

「预览 PVW」是准备中的画面；「播出 PGM」是 OBS / vMix 实际读取的画面。修改预览不会自动改变播出，必须执行切出。

## 2. 第一次使用：建立一场赛事

### 2.1 选择工程

首次打开会显示内置的银石站演示工程。所有车手、车队和成绩均为虚构样例。

开始正式工作前，建议先选择一种方式：

- 点击顶部「打开工程」，选择 `examples/空白赛事.apex.json`。
- 或点击「导出工程」保存当前演示，再直接修改各项资料。

打开工程会替换当前数据并清空播出。若当前工程仍需保留，请先导出备份。

### 2.2 填写赛事资料

1. 进入「赛事管理」。
2. 填写赛事英文名、赛事副标题、分站 / 轮次、赛道名称和举办地。
3. 填写赛道长度、弯道数、天气、气温、赛道温度、湿度和风速。
4. 如有需要，填写默认滚动公告。
5. 点击「导入赛事标志」可加入 PNG、JPEG 或 WebP 图片；单张图片必须小于 1 MB。
6. 点击「保存赛事资料」。

赛事资料属于共享数据，保存后，已上屏的相关字幕会立即更新。

### 2.3 设置比赛场次

在「比赛场次」区域可以：

- 点击已有场次的「切换」按钮，切换当前工作场次。
- 点击「＋ 新场次」添加练习、排位或正赛。
- 修改场次名称、计时类型、当前圈、总圈数和计划时间。
- 点击「保存当前场次」。

计时类型决定默认排序：

- 自由练习：按有效最佳圈速升序。
- 排位赛：按有效最佳圈速升序。
- 正赛：按手动或接口提供的 `position` 排序。

每个场次的计时数据独立保存。切换场次会清空播出、暂停时钟和演示模拟，防止上一场次的画面误上屏。

### 2.4 设置比赛时钟

1. 在「比赛时钟」选择「倒计时」或「正计时」。
2. 在秒数输入框填写初始值，例如 1 小时填写 `3600`。
3. 点击「设置 / 重置」。
4. 点击「开始 / 继续」运行，点击「暂停」冻结当前时间。

正常退出和重新启动后，时钟保持暂停，需由操作员确认后再继续。

## 3. 管理车手与车队

### 3.1 手动编辑

1. 进入「车手与车队」。
2. 点击车手卡片打开编辑器。
3. 填写车号、姓名、英文名、简称、车队、组别、国籍代码、赛车型号、车队颜色、发车位置和积分。
4. 如需形象照，点击「导入形象照」。图片支持 PNG、JPEG、WebP，且小于 1 MB。
5. 点击「保存车手」。

车号必须唯一。国籍使用 `CHN`、`GBR`、`ITA` 等三字母代码。相同车队名称的车手会自动归为同一车队。

点击「＋ 新增车手」可添加新卡片。删除车手会同时删除该车手在所有场次的计时和相关图层引用，操作前请确认。

### 3.2 使用名单 CSV

推荐先点击「导出名单」，在导出的文件上修改，再重新导入。也可点击「CSV 模板」或打开 `examples/车手导入模板.csv`。

CSV 使用 UTF-8 编码，表头为：

```csv
number,name,english,short,nation,team,category,car,color,grid,points
```

导入规则：

- `number` 和 `name` 必填。
- 按车号匹配：已有车号更新资料，新车号添加车手。
- 导入名单不会自动删除未出现在 CSV 中的车手。
- CSV 内不能有重复车号。
- 为避免资料错配，导入完成后会清空播出。

## 4. 录入实时计时

### 4.1 手动录入

进入「实时计时」，点击相应单元格进行修改。可录入：

- 排名、完成圈数。
- 最佳圈速、上一圈。
- 距领先者、距前车。
- 状态、轮胎、S1 / S2 / S3 分段。
- 处罚或调查说明。

圈速输入支持 `1:44.326` 或 `104.326`。分段输入使用秒，例如 `32.100`。CSV 和 HTTP 接口中的圈速、分段则使用整数毫秒。

正赛名次以 `position` 为准，软件不会根据差距文字反推名次。练习和排位中，没有有效最佳圈速的车手排在后面。

状态说明：

| 状态 | 含义 |
| --- | --- |
| RUN | 正常参赛 |
| PIT | 正在维修区 |
| OUT | 已出站 / 离开比赛状态，按赛事数据使用 |
| DNF | 未完赛 |
| DNS | 未发车 |
| DSQ | 取消资格 |

这些状态是显示数据，不会自动触发裁判判罚或名次调整。

### 4.2 进站计时

1. 车辆进站时，在该车手一行点击「进站 PIT IN」。
2. 软件记录进站时间，状态变为 `PIT`。
3. 车辆出站时，点击「出站 PIT OUT」。
4. 软件保存本次 PIT IN → PIT OUT 的经过时间，增加停站次数，并开始新的驾驶时段。

该时间表示维修区经过时间，不等于车辆静止换胎时间。

### 4.3 导入计时 CSV

1. 准备 UTF-8 CSV，或先点击「导出计时 CSV」获得当前格式。
2. 点击「导入计时 CSV」。
3. 选择文件并确认结果。

计时按车号写入当前场次。所有行先校验再提交；任意一行不合法，整批不会写入。

示例表头：

```csv
number,position,laps,bestMs,lastMs,gap,interval,status,tyre,s1,s2,s3,penalty
```

### 4.4 使用 HTTP 接口

本机计时系统可向 `POST /api/timing` 推送 JSON。写请求需要本次启动的随机令牌：

1. 进入「输出与设置」。
2. 点击「显示本次启动的接口令牌」。
3. 在请求的 `X-Apex-Token` 请求头中使用该令牌。

完整字段、示例和读取接口见 [本机数据接口](API.md)。不要把令牌放进直播画面或发送到不受信任的页面。

外部计时写入后会停止演示模拟。软件不会自动计算 GAP、INTERVAL、圈数或官方名次，计时适配器应提供这些字段。

### 4.5 演示模拟

「启动演示模拟」每 2.5 秒更新圈速和差距，用于检查画面。它不会模拟完整比赛，也不会自动增加圈数。

任何手动或外部计时录入都会停止模拟。正式播出前应确认顶部数据来源和计时内容，不要将演示值当作真实成绩。

## 5. 字幕预览与播出

### 5.1 常用操作

| 操作 | 结果 |
| --- | --- |
| 单击图层 | 选中并编辑，不改变播出 |
| 右键图层 | 加入或移出预览 |
| 双击图层 | 立即切出该图层，保留其他播出图层 |
| SPACE | 将整个预览切出到播出 |
| ESC | 立即清空播出，保留预览 |
| 1–9 | 切换前九个图层的预览状态 |
| Ctrl+S | 导出完整工程 |

输入框、文本框、下拉框或按钮有焦点时，SPACE 不触发全局切出。ESC 仍会紧急清屏；车手编辑弹窗打开时，ESC 优先关闭弹窗。

### 5.2 编辑图层属性

1. 单击图层。
2. 在右侧设置标题、正文、车手、组别、榜单数据、页码和每页行数。
3. 按需设置形象照、国籍、车队、进站计时和自动翻页开关。
4. 设置 X / Y 位置、宽度、缩放和自动下屏时间。
5. 点击「加入预览」检查效果。
6. 点击「切出此图层」，或按 SPACE 发布整个预览。

「自动下屏」单位为秒，`0` 表示常驻。计时从实际切出时开始，而不是从编辑预览时开始。

「恢复默认布局」只恢复当前图层的位置、宽度与缩放。

### 5.3 图层组合与顺序

- 图层可以组合叠加。
- 拖动图层按钮可调整堆叠顺序。
- 同位置的主要信息条、整版信息和回放角标会自动互斥。
- 「从播出复制」可将当前 PGM 组合复制回 PVW。
- 「清空预览」只清空 PVW，不影响正在播出的 PGM。
- 「下屏此图层」只关闭当前选中的播出图层。
- 「恢复上次播出」可恢复清屏前的组合，实时数据仍使用当前值。

默认布局适合常见 12 台赛车组合。改变行数、字号、位置或图层组合后，请先在预览检查越界和重叠。

### 5.4 场景预设

1. 在 PVW 准备好一组图层。
2. 点击「保存当前场景」，输入名称，例如「排位」「正赛」或「赛后」。
3. 之后从下拉框选择场景，点击「加载到预览」。
4. 检查无误后按 SPACE 切出。

场景加载到预览，不会直接上屏。

### 5.5 旗号与成绩确认

- 在「赛事管理」或播出控制下方选择旗号，只更新共享状态。
- 点击「旗号字幕 → 预览」，再切出，才会显示旗号字幕。
- SC、VSC、FCY 等状态是否适用由赛事规则和官方数据决定。
- 最终成绩默认显示 `PROVISIONAL / 暂定`。
- 只有成绩得到正式确认后，才勾选「最终成绩已经官方确认」，画面才会显示 `OFFICIAL`。

处罚文字仅用于显示，软件不会自动加罚时、调整排名、计算积分或冠军。

## 6. 接入 OBS Studio

1. 保持 APEX 运行。
2. 进入「输出与设置」，复制「透明输出地址」。
3. 在 OBS 中添加「浏览器」源。
4. 将地址粘贴到 URL。
5. 宽度填写 `1920`，高度填写 `1080`。
6. 帧率设置为 50 或 60，与节目制作设置一致。
7. 在 APEX 中切出一个图层，确认 OBS 画面同步出现。

通常为 `http://127.0.0.1:9860/output`。若端口被占用，桌面版会尝试 9861–9869，因此不要手动沿用旧端口，应复制当前地址。

输出页面背景透明，控制台中的棋盘格不会进入 OBS。

## 7. 接入 vMix

1. 在 vMix 中添加 **Web Browser** 输入。
2. 使用 APEX 显示的 `/output` 地址。
3. 设置 1920 × 1080 画布。
4. 切出一个测试图层，确认画面和透明区域正常。
5. 正式播出前，按实际帧率和图层组合进行联调。

## 8. 输出地址与检查模式

| 地址 | 用途 |
| --- | --- |
| `/output` | 正式透明合成输出 |
| `/preview` | 透明预览，只用于监看 |
| `/output?layer=tower` | 单图层输出，只显示已上屏的排行榜 |
| `/output?background=black` | 黑底检查 |
| `/output?background=green` | 绿底输出 |
| `/output?guides=1` | 显示 90% 安全框，不用于正式播出 |

在「输出与设置」可选择不同模板生成单图层地址。单图层仍遵循播出状态：该图层未上屏或输出已暂停时，不会显示内容。

「暂停输出」会暂时清空所有输出地址，但保留播出组合。点击「恢复输出」后继续显示。

## 9. 主题、工程与备份

### 9.1 修改主题

1. 进入「输出与设置」。
2. 在「字幕主题」设置强调色、面板底色、文字颜色、不透明度、榜单字号和姓名显示方式。
3. 点击「更新预览主题」。
4. 在 PVW 检查后切出。

主题与布局不会绕过预览直接修改播出。

### 9.2 导出与打开工程

- 点击「导出工程」或按 Ctrl+S，下载完整 `.apex.json`。
- 工程包含各场次计时、名单、内嵌图片、预览 / 播出模板和场景预设。
- 建议在每个比赛日前导出一份，并使用日期和场次命名。
- 「打开工程」会替换当前数据、清空播出并暂停时钟。

### 9.3 自动保存位置

桌面版通常保存到：

```text
%APPDATA%/apex-race-graphics/projects
```

源码服务器版保存到项目目录的 `data/`。可通过 `APEX_DATA_DIR` 指定其他目录。实际位置以「输出与设置」中显示的目录为准。

每次修改自动保存，并保留上一个版本 `.bak`。保存失败时，控制台底部会显示警告。

## 10. 常见问题

### 输出页面没有字幕

依次检查：

1. APEX 是否仍在运行。
2. 控制台是否显示「本地服务已连接」。
3. 图层是否已切出到 PGM，而不仅是加入 PVW。
4. 「输出与设置」是否处于「暂停输出」状态。
5. OBS / vMix 是否使用当前实际端口。
6. 单图层地址中的模板是否已经上屏。

### 9860 端口被占用

桌面版自动尝试 9861–9869。重新复制「输出与设置」中的地址并更新 OBS / vMix 浏览器源。

### 浏览器源显示断开或旧画面

确认 APEX 正在运行后，刷新 OBS 浏览器源或重新加载 vMix Web Browser 输入。输出页面会自动重连；断线期间浏览器可能保留最后画面，因此恢复后应核对当前 PGM。

### 修改了属性，但播出没有变化

图层属性和主题需要先进入预览，再执行切出。赛事资料、车手、计时、旗号和成绩确认状态则会在保存后即时更新。

### 图片无法导入

使用小于 1 MB 的 PNG、JPEG 或 WebP 文件。图片会嵌入工程，工程体积也会相应增加。

### 无法保存工程

检查数据目录是否可写，不要从只读目录或压缩包内运行。便携文件夹版应整体复制到桌面、磁盘或可写移动介质。

### Windows 显示未知发布者

当前便携 EXE 未做商业代码签名。只运行自己构建或从可信发布页面下载的文件，并在发布前核对文件来源和校验值。

## 11. 正式播出前检查清单

- 已导出当前工程备份。
- 赛事、场次、车手和车队资料已核对。
- 演示模拟已停止，真实计时来源正确。
- 当前圈、总圈数、时钟和旗号正确。
- OBS / vMix 使用当前输出地址，分辨率和帧率正确。
- 所有准备使用的图层已检查越界、重叠和透明效果。
- 最终成绩未经确认时保持 `PROVISIONAL`。
- 清屏和恢复上次播出功能已测试。
- 操作员知道 SPACE、ESC 和单图层切出的区别。

## 12. 当前范围

本版本提供本机手动、CSV 和 HTTP 数据驱动的 HTML5 字幕，不包含 SDI Fill/Key、DeckLink、NDI、视频采集、回放录制或计时供应商私有协议。回放按钮只显示回放标识，不录制或播放视频。

服务仅监听本机，不开放局域网控制。接入真实赛事时，应使用获授权的计时数据，并在正式转播前完成现场联调。

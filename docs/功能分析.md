# 功能与数据规则

## 系统结构

APEX 由本地服务、播出控制台和 HTML5 渲染页组成：

1. 数据层保存赛事、车手、各场次计时、预览、播出、主题和场景预设。
2. 控制台通过本机 HTTP 接口提交操作，通过 SSE 接收完整状态快照。
3. 预览页与播出页使用相同的 1920 × 1080 渲染器，分别读取预览组合和播出组合。
4. OBS 或 vMix 将 `/output` 作为透明浏览器源。

运行时不需要外部在线资源。

## 数据更新与发布

实时数据和图层设计采用不同的更新方式：

- 赛事资料、车手、计时、圈数、旗号和官方确认状态是共享实时数据，保存后即时更新相关画面。
- 图层标题、正文、布局、显示开关和主题先保存到预览，执行整体或单图层切出后才进入播出。
- 清屏只关闭播出图层，保留预览与上一个播出组合。
- 打开工程、启动恢复和切换场次会清空播出，避免旧内容误上屏。

## 字幕类型

| 类别 | 模板 |
| --- | --- |
| 计时与排名 | 实时排行榜、分段圈速、最快圈、双车对比、轮胎 / 驾驶时长 |
| 车手与车队 | 车手介绍、车手名单、车队介绍、发车格 |
| 比赛信息 | 赛道信息、天气、赛事日程、比赛时钟、比赛顶栏 |
| 赛事控制 | 赛道旗号、处罚 / 调查、最终成绩、前三名、积分榜 |
| 节目包装 | 进站计时、赛事角标、直播角标、回放、起步回放、暖胎圈、精彩集锦、自定义字幕、滚动公告 |

图层支持组合、拖动排序、位置与缩放调整、分页和自动下屏。同位置的主要信息条、整版信息和回放角标自动互斥。

## 排序规则

- 正赛按输入的 `position` 排序，不根据差距字符串推导名次。
- 自由练习和排位赛按有效 `bestMs` 升序，没有成绩的车手置后。
- 发车格按 `grid`，积分榜按手动填写的 `points`。
- 组别筛选后重新显示组内顺序。

圈速在控制台使用 `分:秒.毫秒` 或秒，在 CSV 与 HTTP 接口中使用整数毫秒。

## 维修区与驾驶时段

PIT IN 记录服务器时间并将状态设为 `PIT`；PIT OUT 计算本次维修区经过时间、增加停站次数并开始新的驾驶时段。该值不代表车辆静止换胎时间。

## 旗号与官方数据

旗号、处罚、积分、排名和成绩确认均由操作员或获授权的计时适配器提供。软件不作为裁判规则引擎，不自动加罚时、调整官方名次、计算积分或冠军。

最终成绩默认显示 PROVISIONAL；只有操作员明确确认后才显示 OFFICIAL。

## 演示模拟

演示模拟每 2.5 秒更新圈速与差距，不模拟完整比赛，也不自动增加圈数。手动或外部计时录入会停止模拟。

## 接入真实制作环境

接入前应准备：

1. 获授权的计时数据、字段说明、更新频率和更正机制。
2. 赛事组别、车组、发车和成绩确认流程。
3. OBS 或 vMix 的版本、分辨率、帧率与浏览器源设置。
4. 需要使用的图层组合、行数、字号和安全框要求。

当前版本不包含 SDI Fill/Key、DeckLink、NDI、视频采集、回放录制或计时供应商私有协议。

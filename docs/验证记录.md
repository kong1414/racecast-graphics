# 验证记录

验证环境：Windows 10 x64，Node.js 24.13.0，Electron 44.4.5，Electron Builder 26.15.3，Playwright 1.63，Microsoft Edge。

## 自动化验证

- `npm test`：12 / 12 通过。覆盖预览 / 播出隔离、整体与单图层切出、清屏恢复、比赛时钟、进出站计时、计时事务校验、场次独立性、排序、工程校验、图层互斥、自动下屏、删除清理、HTTP 认证、SSE 与保存恢复。
- `npm run test:ui`：3 / 3 通过。覆盖 28 种模板实际渲染、标题预览隔离、车手编辑、时钟、暂停输出、透明背景、文字转义、CSV、工程导入导出、场景预设和单图层下屏。
- `npm run package:win`：Windows 完整运行目录与便携 EXE 构建成功。
- `node tests/smoke-exe.cjs`：打包程序启动、PVW / PGM、进站计时、整体切出、独立 HTML5 输出窗口、透明画布与紧急清屏通过。

测试使用隔离临时数据，不修改正式工程。浏览器测试的临时结果不会写入文档截图目录。

## 实际运行检查

- 桌面控制台成功连接本地服务。
- 预览整体切出后，播出状态包含排行榜、时钟、顶栏和赛事角标。
- `/output` 实际显示 12 位演示车手与当前赛事数据。
- 内置初始状态与 `examples/演示工程.racecast.json` 内容一致。
- 默认演示为银石站，12 位车手与 6 支车队均使用明确的虚构演示名称。
- README 本地链接、MIT 许可证元数据与发布文件排除规则已检查。

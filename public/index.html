HTML5 播出

EXE 需要保持运行；本版本为本机输出。端口占用时自动选择 9861–9869，请以这里显示的地址为准。

单图层地址仍遵循播出启用状态。停止输出会将所有播出地址透明清空。

字幕主题 应用到预览

主题、字号、布局和属性均在切出后生效。所有字幕均可单独调整位置、宽度、缩放和自动下屏时长。

数据接入

支持手动录入、车手名单 CSV、计时 CSV、JSON 工程，以及本机 HTTP JSON 推送接口。

发送数据前先导入车手名单。车号必须匹配；单位为毫秒。外部数据写入后演示模拟自动停止。

本版不包含任何赛事供应商的私有协议。实际计时接入需要按官方授权的数据格式编写适配器。

操作与保存

SPACE 切出全部预览　ESC 紧急清屏
1–9 切换前九个图层的预览状态
Ctrl + S 导出工程

输入框编辑时不会触发切出快捷键。清屏只清除播出，可从上次播出恢复。

每次修改自动保存，并保留上一个版本的 .bak 备份。启动、导入工程和切换场次时播出清空，防止旧字幕误上屏。

所有默认车手、车队、圈速和积分均为演示资料，非真实赛事成绩。
